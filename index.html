/about

A feature isn't done when it's built. It's done when someone has tried hard to break it.

I'm a QA Engineer at Rubico Tech, where I've spent 6+ years testing web apps, native and hybrid mobile apps, and the APIs behind them. I write the test plans, author the test cases from the business logic, and own the call on whether a build is ready to go.

Most of my days sit between the UI and the backend. When a multi-step workflow fails, I trace it through Postman and Datadog to the exact step that broke, so developers get a reproducible bug instead of a vague report.

I've led QA on platforms used in more than 20 countries, run localization testing in Portuguese, Indonesian, Spanish and French, and mentored junior testers on automation and test strategy.
